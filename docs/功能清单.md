# 星域臻旅 司机端 App — 页面与功能清单

> 供后端对接使用。按「页面 → 元素 → 按钮/操作 → 需要的后端能力」组织。
> 应用为 Compose Multiplatform（Android 为主），数据多为本地示例，待接后端。

## 0. 全局结构与启动流程

- 启动 → EntryScreen（入口页：**登 录** / **注 册** 两个按钮）
- 未登录可先看政策页（8 份）：用户服务协议 / 隐私政策 / KYC 实名认证合规条款 / 退款政策 / 数据留存与审计合规政策 / 免责声明 / 合规最终说明 / 终端用户软件许可协议
- 登录成功 → 主界面，底部 5 个 Tab：
  - 首页 Home / 行程 Trips / 聊天 Chat / 财务 Finance / 我 Profile
- 启动时自动检查版本；有新版弹强制更新弹窗（正在更新 vX / 进度 / 错误重试）
- 绝大多数二级页为覆盖层（全屏），带左上角返回按钮

## 1. 入口 / 账号

### EntryScreen
- 元素：品牌 Logo、「星域臻旅」、标语「— 尊荣邀制 · 至尊之旅 —」
- 按钮：**登 录**、**注 册**

### LoginScreen（登录）
- 输入：手机号/邮箱、密码（**显示/隐藏密码** 眼睛按钮）
- 复选：我已阅读并同意《用户服务协议》《隐私政策》（可点开对应政策页）
- 按钮：**登录**、**注册**、**忘记密码？**、返回
- 其它登录方式（第三方）

### ForgotPasswordScreen（忘记密码）
- 输入：邮箱地址；说明「验证码会发送到该邮箱」
- 按钮：**发送验证码**、返回

### VerifyCodeScreen（验证码）
- 输入：6 位验证码；显示「验证码已发送至 …」
- 按钮：**确认**、**重发（60s 倒计时）**

### ResetPasswordScreen（重建密码）
- 输入：新密码、确认密码（≥8 位，英文/数字/符号）
- 校验：两次密码不一致提示
- 按钮：**重建密码**、返回

### RegisterScreen（注册）
- 头像（拍照/相册）、昵称、手机号、微信号、邮箱、密码、确认密码
- 性别、生日日期（原生日历）、居住地：州属/城市/邮编/门牌及街道
- KYC 证件上传：马来西亚身份证 / 驾照 / 护照（拍照上传，仅支持拍照）
- 勾选：我已阅读并同意《用户服务协议》《KYC实名认证合规条款》
- 按钮：**注 册**、返回

### 政策页（8 份，通用排版）
- UserServiceAgreementScreen / PrivacyPolicyScreen / KycPolicyScreen / RefundPolicyScreen / DataRetentionPolicyScreen / DisclaimerScreen / FinalComplianceScreen / EulaScreen
- PolicyScreen：平台政策与协议列表（点击进入对应政策）

- 人数：大人 / 小孩；行李

## 4. 聊天

### ChatScreen（会话列表）
- 会话行（头像、名称、最后一条消息、未读角标 99+）
- 「官方通知」入口
- 点击会话 → ChatConversationScreen

### ChatConversationScreen（会话）
- 消息气泡（文本/图片/语音/文件/名片/位置）、发送状态 Tick、已读
- 输入栏：文本输入「发消息…」、**发送**、**+ 更多面板**：相册 / 拍照 / 位置 / 名片 / 文件 / 语音 / 语音通话 / 视频通话
- 语音：按住录音（**松开 发送**）、播放
- 顶部：返回、标题、更多（→ ChatDetailScreen）
- 名片发送：星域臻旅 · 公司名片
- 需要后端：消息收发/历史、已读回执、图片/文件上传、位置、名片、未读数

### ChatDetailScreen（聊天详情）
- 开关：**置顶聊天**、**消息免打扰**
- 入口：**查找聊天内容**（→ ChatSearchScreen）
- 按钮：**清空当前聊天记录**（二次确认「确定清空与「…」的聊天记录吗？」）

### ChatSearchScreen（查找聊天内容）
- 搜索框 + **搜索** 按钮、日期选择入口
- 结果分类：图片与视频 / 文件 / 链接 / 名片 / 位置 / 语音 / 日期
- 空态：没有找到相关聊天记录

### ChatSettingsScreen（聊天设置）
- 开关：使用听筒播放消息 / 使用独立的发送按钮 / 保留查看过的原图原视频 / 自动下载在其他设备查看过的内容

### ChatRecordsScreen（聊天记录管理）
- 按钮：**导出全部聊天记录**（导出完成提示）、**清空全部聊天记录**（二次确认）

### CallScreen（语音/视频通话）
- 按钮：**静音**、**听筒**、**扬声器**、**挂断**；视频画面
- 需要后端：通话信令/呼叫状态

### PersonDetailScreen（个人详情）
- 姓名、ID、所属公司、平均评分、好评率、最近评价记录
- 按钮：**发送消息**（→ 会话）

## 5. 财务

### FinanceScreen
- 统计卡：今日单数 / 今日薪资 / 今日报销 / 代收新币 / 代收马币 / 当月累计薪资 / 当月累计报销
- 按钮：**提交报销**（→ ExpenseSubmitScreen）、**流水记录**（→ LedgerScreen）
- 我的钱包入口（见 5.3）

### 5.1 ExpenseSubmitScreen（提交报销）
- 字段：类型（下拉：加油/TNG/RFID/Autopass/洗车/维修/住宿/其他）、归属车辆（下拉）、金额（货币 MYR/SGD）
- 收据证明上传：拍照 / 相册 / 文档（已上传收据）
- 按钮：**提交报销** → **确认提交**；返回
- 需要后端：报销单创建、收据上传、车辆列表

### 5.2 LedgerScreen（流水记录）
- 筛选胶囊：**全部 / 报销 / 薪资 / 转账**
- 流水卡列表（类型徽标、日期、标题、金额、状态）→ 点击进交易详情
- 需要后端：流水列表（按类型）

### TransactionDetailScreen（交易详情）
- 顶部：左上**返回**、右上**收据**（调用系统分享/打印收据文本）
- 金额（货币）+ 带正负号金额（+ 绿 / - 白）
- 分界线
- 明细：日期时间 / 来自 / 类型（转账·薪资·报销）/ 报销类型（仅报销）/ 订单编号（有则显示）/ 交易编号 / 备注（有则显示）/ 状态
- 底部：**完成**
- 需要后端：流水明细（交易编号、订单编号、备注、状态、方向 ±）

### 5.3 WalletScreen（我的钱包）
底部胶囊快捷栏：**首页 · 转账 · 扫码（中间圆形凸起）· 流水 · 申请**

#### 5.3.1 首页
- 1 张大卡：钱包余额
- 2 张并排卡：代收 SGD / 代收 MYR
- 点击卡片 → 对应钱包账户页

#### 5.3.2 转账（WalletTransferTab）
- 1 张卡，4 步折叠表单（展开某步时上一步自动收回）：
  1. **从**：三个帐户（货币｜金额）→ 选后收回、把帐户显示在步骤号旁、自动展开步骤2
  2. **给**：**+ 新转账**、过往帐户（姓名 + 帐户号码）→ 选后进步骤3；点新转账 → 新转账页（帐户号码搜索框 + **搜索** → 显示姓名/号码 → 选择 → 步骤3）
  3. **转账金额**：货币、金额、分界线、数字键盘（7/8/9、4/5/6、1/2/3、**打叉**、0、**完成**）；从右到左输入、始终两位小数
  4. **其他详情**：备注输入框、付款日期（默认当天，原生日历可改）；**完成按钮固定在卡片最底部**
- 完成后收回并显示汇总（1 从+帐户号码 / 2 给+帐户号码 / 3 金额 / 4 备注+付款日期）+ **继续**
- **确认详情页**：从（我的钱包/…）+ 帐户号码；给 + 姓名 + 帐户号码；分界线；转账日期；**确认转账**
- **转账时间线页**：我方待发送 → 我方已发送 → 对方待接收 → 对方已接收 → 完成（逐步 ✅）；**完成** 结束
- 需要后端：账户余额、收款人搜索、转账下单、转账状态回调、付款日期、备注

#### 5.3.3 扫码（WalletScanTab）
- 底部胶囊：**扫码 / 收款**；胶囊上方 **相册**、**闪光灯**
- 扫码：扫码框、「二维码放入框内」；相册选图识别；闪光灯开手电筒
- 收款：二维码卡片（顶部姓名 + 二维码）；下方胶囊 **下载二维码 / 输入特定金额**；下载二维码存相册；输入金额 → 一次性金额码，显示货币金额 + **60 秒有效倒计时**，过时自动返回
- 需要后端：收款二维码生成/金额码、有效时间、扫码结果解析

#### 5.3.4 流水
- 直接复用流水记录页（LedgerScreen，含交易详情）

#### 5.3.5 申请（WalletApplyTab）
- 申请时间（当天日期+时间，自动）
- 申请类型（弹出选项）：**预支薪水 / 申请发薪 / 开销资金**
  - 预支薪水 / 申请发薪 → 显示 **货币 MYR ｜ 金额输入框**
  - 开销资金 → 显示 **货币 SGD/MYR ｜ 金额输入框**
- 底部：**确认申请**（提交后弹提示）
- 需要后端：申请单提交（类型/货币/金额/时间）

#### 5.3.6 钱包账户页（WalletAccountScreen）
- 标题（钱包余额 / 代收 SGD / 代收 MYR）+ 返回
- **帐号** + **复制**按钮（复制到剪贴板，「已复制」提示）
- 1 张卡：**可用余额（货币）** / **当前余额（货币）**，各显示金额
- 1 张卡：**交易流水记录**（该账户记录）→ 点击进交易详情
- 需要后端：账户信息（帐号、可用余额、当前余额）、该账户流水

### 5.4 MyReviewsScreen（我的评价）
- 概览：平均评分、好评率、共 N 条评价
- 评价卡列表（乘客名、星级、内容、行程标题、日期）
