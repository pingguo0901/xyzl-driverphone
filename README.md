# 星域司导 · 手机司机端

Kotlin Multiplatform (KMP) + Compose Multiplatform 构建的星域司导手机司机端应用。

## 技术栈

- Kotlin Multiplatform (KMP)
- Compose Multiplatform
- Android / iOS 双端

## 快速开始

```bash
# 安装依赖
./gradlew build

# Android 运行
./gradlew :composeApp:assembleDebug
```

## 下载
